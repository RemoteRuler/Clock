Remote Ruler is a comprehensive suite of web-based tools meticulously crafted to empower precise time management and insightful temporal analysis. From real-time digital displays to advanced calculators and essential utility features, Remote Ruler is engineered to be your indispensable modern time toolkit.

## ✨ Features

*   **Tasbih Counter:** A beautifully designed digital Tasbih with target tracking, presets, session stats, and haptic feedback.
*   **Digital Clock:** A sleek, real-time digital clock for accurate time display.
*   **Stopwatch:** A precision stopwatch with lap tracking, best/worst lap highlighting, and a visual progress ring.
*   **Age Calculator:** Accurately determine age based on any given birth date.
*   **Death Calculator:** A unique tool to calculate time remaining until a specified future date or event.
*   **Location Tracker:** Pinpoint and display your current geographical coordinates.

## 🚀 Getting Started (Admins Only)

To set up and run Remote Ruler on your authorized local machine:

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/RemoteRuler/Clock.git
    ```
2.  **Navigate to the Project Directory:**
    ```bash
    cd Clock-main
    ```
3.  **Open in Your Browser:**
    Open the `index.html` file in your preferred web browser. 
    The `index.html` file serves as the central hub, providing intuitive navigation to all the specialized tools within Remote Ruler.

## 🛠️ Technologies Used

*   **HTML5:** Foundational markup for robust structure.
*   **CSS3:** Employed for sophisticated styling, custom per-page color themes via CSS variables, and responsive design.
*   **JavaScript (ES6+):** Powers all interactive functionalities and complex calculations.
*   **Google Fonts (JetBrains Mono & Amiri):** Selected for readability, modern developer aesthetics, and elegant Arabic typography.

## 🎨 Design Philosophy

Remote Ruler is meticulously designed with a focus on cleanliness, minimalism, and a professional aesthetic. It boasts a fully responsive layout ensuring a flawless user experience across an extensive range of devices. Each internal tool features its own distinct color theme (e.g., Midnight Blue for the Clock, Emerald/Gold for Tasbih, Warm Amber for Age Calculator) tied together by a unified, modern styling system.
